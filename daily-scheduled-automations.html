Daily Scheduled Automations

MAG Automation Run Schedule

This is the single reference for every automation that runs on a daily schedule across the MAG stack — the n8n workflows on Google Cloud Run, the Supabase Edge Functions, and the daily Claude cloud routines. It lists what runs, when it runs, and where it lives, so anyone can see the whole morning at a glance. It does not cover automations that run hourly, weekly, or monthly, or that are triggered manually.

How to Read This

  • All times are Philippine Time (PHT, UTC+8). The underlying schedules are stored in UTC and converted here for readability.
  • "Mon–Fri" means weekdays only — those automations do not run on weekends. A few Claude routines run every day; each entry says which.
  • The n8n container is kept warm 5:50–7:05 AM Mon–Fri so the 6:00–7:00 AM batch does not hit a cold start.
  • "Active" vs "Paused": Active automations are running now. Paused ones are configured but currently switched off — listed so nothing is lost track of.

How It All Runs

Three layers make up the daily run:

  • Supabase pg_cron — a free scheduler inside the Supabase database. It fires the n8n workflow webhooks and the MAGTestProject Edge Functions on their staggered morning schedule.
  • n8n on Google Cloud Run — hosts the workflows. It wakes on each scheduled webhook call, runs the workflow, and scales back down when idle. A Cloud Scheduler keep-warm window (5:50–7:05 AM Mon–Fri) guarantees it is awake for the batch.
  • Claude cloud routines — scheduled Claude agents that run independently in the cloud on their own cron schedules.

Because the schedules are staggered a few minutes apart, the workflows do not all fire at once. Times and run days are managed outside n8n (in pg_cron, the Edge Function cron jobs, and the routine schedules) — contact your automations admin to add, remove, or change any run time.
