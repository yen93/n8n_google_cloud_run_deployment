AC Notes Automation — Cold Leads Follow-up Sequence

User Guide

This automation keeps your ActiveCampaign deals up to date with the Cold Leads outreach follow-up email sequence. Every weekday morning it checks which sequence emails have gone out and automatically writes a note onto the matching deal in ActiveCampaign — so anyone looking at a deal can see, at a glance, exactly which follow-up emails a cold lead has received, without anyone logging notes by hand.

What This Is

This is a hands-off, scheduled automation that runs inside the MAG team's n8n workflow tool. The Cold Leads outreach sequence sends prospects up to five emails — an intro email, then four follow-ups. Each of those sends is tracked in a table. This automation reads that table each morning and, for every lead who has been sent a given email but doesn't yet have a note recorded for it, it adds a note to that person's deal in ActiveCampaign marking the stage. It then flags the record as done so the same note is never added twice.

In short: it turns "email 3 was sent to this cold lead" into a visible note on their ActiveCampaign deal, automatically, for all five stages of the sequence. It is the Cold Leads counterpart to the Soc Med AC Notes sequence and runs from the same underlying workflow.

Who This Guide Is For

Anyone on the MAG sales or marketing team who works with the Cold Leads outreach sequence in ActiveCampaign, or who reviews deals and relies on the notes being accurate. You do not need to run or configure anything — this section explains what the automation does on your behalf and how to check it is working. Setting up or changing the automation itself is an admin task (see How It Was Built).

How to Use It

There is nothing to start or click — the automation runs on its own on a schedule. To make use of it and to confirm it is doing its job:

  1. Work the sequence as normal. As the Cold Leads outreach emails go out and the send dates are recorded, this automation picks them up automatically on the next morning's run.
  2. Open a lead's deal in ActiveCampaign (at myadventuregroup.activehosted.com).
  3. Look at the deal's Notes. For each follow-up email that has been sent, you should see a corresponding note recording that stage of the sequence.
  4. Expect notes to appear the morning after a send. If an email was sent today, its note will typically show up during the next weekday morning run, not instantly.

What to Expect

  • Runs weekday mornings, Philippine time. The five stages are processed in sequence between 6:40 AM and 7:00 AM PH time, Monday to Friday: intro at 6:40, 1st follow-up at 6:45, 2nd follow-up at 6:50, 3rd follow-up at 6:55, 4th follow-up at 7:00.
  • Notes land on the deal, not the contact. Each note is added to the lead's ActiveCampaign deal. A lead only gets notes if they have a matching deal in ActiveCampaign.
  • Each note is added once. Once a stage's note has been written, the record is flagged so the automation never duplicates it on later runs.
  • It only catches up on what's outstanding. Every run adds notes only for sends that have a recorded send date but no note yet — so if a run is missed, the next run picks up anything left over.
  • No email is sent by this automation. It does not send the outreach emails themselves — it only records notes about emails that were already sent by the sequence.

Known Limitations

  • A lead must exist in ActiveCampaign as both a contact and a deal. The automation matches the sequence record to a contact by email, then to that contact's deal. If there is no matching contact, or the contact has no deal, no note is added for that person.
  • It depends on send dates being recorded. A stage's note is only added once that stage's email has a recorded send date. If a send date is missing, the note won't be added even though the email may have gone out.
  • Weekends are skipped. The automation does not run Saturday or Sunday (PH time). Notes for weekend sends are added on the following Monday morning.
  • It runs on a morning schedule, not in real time. Notes are not written the instant an email is sent — expect a lag until the next weekday morning run.
  • It does not remove or edit notes. It only adds new ones. Cleaning up incorrect notes is a manual task.

How It Was Built (Architecture & Tech Stack)

The automation is part of a single n8n workflow named AC Notes Automation (Follow up sequence), which holds both the Soc Med and the Cold Leads branches. The Cold Leads side has five near-identical branches, one per email stage. Each branch works like this:

  • Trigger — a Webhook that is called each morning by an external scheduler (see below). This replaces n8n's built-in timer, which does not run reliably on this cloud setup.
  • Read outstanding threads — a SQL query against the cold_leads_follow_up_sequence_threads table joins to activecampaign_contacts (by email) and activecampaign_deals (by contact) and selects only rows where that stage's email was sent but its note has not yet been added.
  • Add the note — for each matching record, an HTTP request posts a note to the ActiveCampaign deal via the ActiveCampaign API (/api/3/deals/{deal}/notes). Items are processed in small batches.
  • Mark as done — the record in cold_leads_follow_up_sequence_threads is updated to flag that stage's note as added, so it is never re-added.

The whole workflow is triggered by Supabase pg_cron, a free scheduler running in the database, which calls each branch's webhook on a staggered weekday-morning schedule. Tech stack:

  • n8n — the workflow automation engine, running on Google Cloud Run.
  • ActiveCampaign — the CRM where the deal notes are written (via its REST API).
  • Supabase (PostgreSQL) — stores the sequence-tracking tables and the n8n workflow state, and hosts the pg_cron scheduler that fires the daily runs.
  • Google Cloud Run — hosts the n8n service; it wakes on the scheduled webhook call, runs the workflow, and scales back down when idle.

Troubleshooting

  • A lead's deal is missing an expected note: confirm the lead exists in ActiveCampaign as a contact (matched by email) and has a deal — no deal means no note. Then confirm the relevant email has a recorded send date.
  • Notes haven't appeared for a recent send: they are added the next weekday morning, not instantly. Check again after the next run (6:40–7:00 AM PH), and note that weekend sends are picked up on Monday.
  • A whole morning's notes are missing: the automation may not have run. Ask your admin to confirm the scheduled webhook calls fired and returned successfully.
  • Notes stopped appearing entirely: the ActiveCampaign connection may need attention, or the workflow may have been switched off. Ask your admin to confirm the workflow is Active and its ActiveCampaign credential is valid.
  • A note looks wrong or duplicated: the automation adds each stage's note only once and does not edit notes, so unexpected content usually points to the underlying sequence data — raise it with your admin.
